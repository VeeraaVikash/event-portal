# Demo assets

Sample files for trying the post-event report workspace, referenced by
`scripts/seed_demo.php`. Nothing here is real event material.

| File | Use |
|---|---|
| `inauguration.jpg`, `keynote_session.jpg`, `valedictory.jpg` | photographs — embedded as pages in the report |
| `attendance_sheet.pdf`, `expense_bills.pdf` | bills and attendance proof — stored and linked from the annexure |

The photographs and both PDFs are generated placeholders.

Photographs are capped at two per day of the event, so a one-day event takes two
of the three images here and a two-day event takes all three.

# Demo assets

Sample files for trying the post-event report workspace, referenced by
`scripts/seed_demo.php`. Nothing here is real event material.

| File | Use |
|---|---|
| `inauguration.jpg`, `keynote_session.jpg`, `valedictory.jpg` | photographs — embedded as pages in the report |
| `keynote_clip.mp4` | video — stored and linked from the annexure with a QR code |
| `attendance_sheet.pdf`, `expense_bills.pdf` | documents — stored and linked from the annexure |

The photographs and both PDFs are generated placeholders. `keynote_clip.mp4` is
`flower.mp4` from MDN's shared assets, released under CC0.
